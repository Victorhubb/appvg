# Meu primeiro projeto; Sistemas de Páginas Estáticas utilizando do Node.js

Fiz um projeto simples a fim de colocar em prática boa parte do meu 
conhecimento teórico

O principal intuito foi distribuir páginas HTML estáticas, para isso foi necessário:
- Organizar o projeto em pastas;
- Distribuir rotas no backend;
- Conectar HTML E CSS;

# Tecnologias que eu utilizei:

- HTML5
- CSS3
- Node.js
- Express
- Dotenv

# Rotas feitas

- /: utilizada para a página inicial (index.html)
- /login: página de login (login.html)
- /cadastro: página de cadastro (cadastro.html)
- /qualquer rota inexistente: página 404 (404.html)

# Para executar o projeto:

- Instale as dependências "npm install"
- Iniciar o servidor "npm start"
- Abrir no navegador "http://localhost:3001"
- Para reiniciar e rodar "npm run dev"
